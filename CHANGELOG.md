## [1.0.0] - 2026-09-08

### Added
- **Initial Public Release of QEVRA Open-Web Discovery Architecture Documentation**:
  - `README.md`: Overview of open-web discovery, core architecture, and project index.
  - `ARCHITECTURE.md`: High-level system architecture, component decoupling, and public vs authenticated flow separation.
  - `DISCOVERY.md`: Comparative breakdown of the open-web discovery paradigm vs social graph feeds and search engines.
  - `RELEVANCE.md`: Multi-factor relevance scoring framework, signals taxonomy, and source diversity constraints.
  - `RSS-INGESTION.md`: Asynchronous RSS/Atom feed parsing, polling schedules, content normalization, and deduplication.
  - `IMAGE-DELIVERY.md`: Media extraction hierarchy, SSRF proxy guards, dynamic WebP transcoding, and request coalescing.
  - `PUBLISHER-DISTRIBUTION.md`: Publisher metadata structuring, topic mapping, and equitable discovery opportunities.
  - `CREATOR-DISCOVERY.md`: Non-walled-garden creator profile aggregation, cross-format indexing, and topic discovery.
  - `SEARCH-VS-DISCOVERY.md`: Comprehensive article detailing cognitive and architectural differences between search and discovery systems.
  - `SCALING.md`: "The Million-Publisher Problem" thought experiment, multi-stage candidate reduction funnel, and edge caching architecture.
  - `SEO.md`: Standards-based technical SEO, structured JSON-LD data, Open Graph meta hygiene, and Core Web Vitals guidelines.
  - `SECURITY.md`: Outbound SSRF protections, payload size limits, rate limiting, and vulnerability disclosure procedures.
  - `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `LICENSE.md`: Open-source community guidelines and MIT License terms.
